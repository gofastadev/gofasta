🚀 Gofasta HTTP Example

Interactive demonstration of the Gofasta HTTP framework

📍 Available API Endpoints

GET /api/v1/health

Health check endpoint

GET /api/v1/info

Application information

GET /api/v1/users

Get all users

GET /api/v1/users/:id

Get user by ID

POST /api/v1/users

Create new user

PUT /api/v1/users/:id

Update user

DELETE /api/v1/users/:id

Delete user
